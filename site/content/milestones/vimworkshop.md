Modal editors are used by developers world wide because of it's minimalism, ability to configure and minimal keystrokes

**Kiran J Rajpurohit** a Homebrew senior conducted this workshop it was a hands-on session .The Audiance had to install Vim configure everything from scratch and get the "Vim Experience" the workshop covered most of the popular vim keystrokes and some nitpicks that can make development easy.

The workshop intended to not only understand how modal editors work but also have the confidence to start using them in real-world projects.
